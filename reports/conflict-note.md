# Merge Conflict Note

## What happened

A merge conflict was deliberately created between the `main` branch and the `feature-project-description` branch.

Both branches modified the same section of `README.md` with different project descriptions.

## How the conflict was resolved

Git could not automatically determine which version to keep, so the conflicting section was opened and resolved manually.

The final version combined the useful information from both branches into one project description.

## Result

The conflict markers were removed, the resolved file was staged, and the merge was committed to `main`.
